# Protocolo de sessão

Abra a sessão classificando brownfield/greenfield e o modo ADR (`requested` ou `selective`). Registre fontes oficiais ou `EVIDENCE GAP`, faça uma pergunta atômica, escreva a decisão fechada e rode impact scan quando houver evidência nova. A cada cinco alterações e no fechamento, execute a auditoria. O STOP depende de saturação comprovada, não de fadiga.

### Checklist de mudança
- impacto classificado: emenda, exceção ou substituição;
- ADR antigo/novo, backlinks, CONTEXT, BL e ROADMAP atualizados na mesma ação;
- nenhum `accepted` contraditório;
- auditoria emitida com GO/NO-GO/BLOCKED.
