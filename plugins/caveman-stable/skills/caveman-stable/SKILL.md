# Caveman Stable

The host runtime applies the output contract automatically while this plugin is enabled. There are no intensity levels, mode commands, mutable state, or per-task activation steps.

Follow `references/output-contract.md` on every response. Compression applies only to conversational prose and must not reduce technical accuracy, safety, evidence, or verification.

Disable or uninstall the plugin to return to normal output. See the plugin README for runtime-specific activation, trust, and rollback details.
